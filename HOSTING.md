# Где разместить RolanPRO CRM

CRM это один HTML-файл (~650 КБ) с встроенной базой данных в localStorage браузера. Для команды нужно его выложить в интернет, чтобы:
- Клиенты могли открыть портал по ссылке (для подтверждения КП и оплаты)
- Монтажники открывали кабинет с телефона
- Письма со ссылками на портал работали
- Telegram/SMS шаблоны вели на реальные URL
- PWA-установка («Добавить на главный экран») заработала

## Вариант 1. Netlify Drop — самый быстрый старт ⭐

**Время: 30 секунд. Идеально для теста.**

1. Откройте https://app.netlify.com/drop в браузере
2. Перетащите файл `rolanpro-crm.html` прямо в окно
3. Через 5 секунд появится URL вида `https://random-name-xxxx.netlify.app/rolanpro-crm.html`
4. **Готово.** Ссылка работает мгновенно по HTTPS

Чтобы CRM открывалась по корню домена (без `/rolanpro-crm.html`):
- Переименуйте файл в `index.html` перед загрузкой
- Или загрузите папку с `index.html` внутри

**Минусы:** случайное имя домена. Чтобы получить нормальный URL — зарегистрируйтесь и привяжите кастомный домен.

## Вариант 2. Vercel + GitHub — production ready

**Время: 5 минут. Идеально для команды.**

Преимущества:
- Авто-деплой при изменениях (push в Git → новый билд через 30 сек)
- Preview-окружения для тестирования
- Аналитика и логи
- Бесплатно на пожизненно для одного пользователя

### Шаги:

1. **Создайте GitHub репозиторий:**
   - https://github.com/new
   - Имя: `rolanpro-crm` (private рекомендую — внутри файлы с настройками)
   - Загрузите `rolanpro-crm.html` через web-интерфейс или git push

2. **Подключите Vercel:**
   - https://vercel.com/signup → войти через GitHub
   - **Add New → Project**
   - Выберите свой репозиторий `rolanpro-crm`
   - Framework Preset: **Other**
   - Build settings: оставьте пустыми (no build)
   - **Deploy**

3. Через ~30 секунд получите URL `https://rolanpro-crm.vercel.app`

4. **Custom domain:** Settings → Domains → добавить ваш домен (например `crm.rolanpro.com`). Vercel пришлёт DNS-записи для добавления у регистратора домена.

### Авто-деплой

Каждый `git push` в `main` ветку → Vercel автоматически собирает новую версию. Можно даже редактировать прямо на github.com через web-интерфейс.

## Вариант 3. Cloudflare Pages — лучшая скорость

**Самая быстрая CDN в мире. Бесплатно для любого трафика.**

1. https://pages.cloudflare.com/
2. Connect to Git → выберите GitHub репо
3. Framework preset: **None**, build command: пустой, output directory: `/`
4. Deploy
5. Получите `https://rolanpro-crm.pages.dev`

Плюсы Cloudflare:
- Бесплатно ВСЁ — даже DDoS-защита, WAF (firewall)
- Точки присутствия в 300+ городах (Россия, ЕС, США, Азия)
- Можно добавить серверные функции (Workers) для прокси Twilio/OpenAI
- Аналитика встроена

## Вариант 4. Свой домен (типа crm.rolanpro.com)

После того как развернули CRM на любом из хостингов:

1. Купите домен на **Namecheap** ($10/год) или **Cloudflare Registrar** ($8.57/год без наценок)
2. У хостинга (Vercel/Netlify/Cloudflare) → Settings → Domains → Add Custom Domain
3. Хостинг покажет DNS-записи. Добавьте у регистратора:
   - `CNAME` → имя `crm`, значение указано хостингом
   - Или `A` запись → IP указан хостингом
4. Через 5-30 минут домен заработает с автоматическим HTTPS-сертификатом

**Совет:** если уже есть сайт RolanPRO.com — поднимите CRM на поддомене `crm.rolanpro.com` через Cloudflare Pages.

## После размещения — что обновить в CRM

### 1. Публичный URL CRM

**Настройки → 🌐 Публичный URL CRM** → впишите ваш URL (например `https://crm.rolanpro.com`).

После этого все ссылки в письмах и SMS на клиентский портал будут вести на реальный URL.

### 2. Allowed Origins для EmailJS

EmailJS → Account → Security → **Allowed Origins** → добавить:
```
https://crm.rolanpro.com
```

### 3. Twilio CORS (для прямой отправки SMS)

Twilio API уже разрешает CORS, но если включён корпоративный VPN — может блокировать `api.twilio.com`. Проверьте в DevTools → Network.

### 4. Stripe domain whitelist (если используете Connect)

Stripe Dashboard → Settings → Branding → добавьте ваш домен. Не требуется для Payment Links, но нужно для Stripe.js Elements.

### 5. PWA-иконка на iPhone

Если хотите чтобы при «Добавить на главный экран» иконка была не дефолтной:
- Откройте CRM в Safari на iPhone
- «Поделиться» → «На экран Домой»
- Готово, иконка с логотипом ROLANPRO появится как у обычного приложения

На Android Chrome покажет промпт «Установить приложение» автоматически.

## Безопасность

⚠️ **CRM хранит API-ключи в localStorage браузера** (Anthropic, EmailJS, Twilio, Stripe). Это нормально для **внутреннего использования**, но опасно для публичного хостинга:

**Что делать:**

### Минимум:

1. **Используйте Restricted/Limited Keys везде где можно:**
   - Stripe: Restricted Key с минимальным набором прав (не Secret Key)
   - Twilio: API Key + Secret вместо Auth Token (можно отозвать одним кликом)
   - Anthropic: ключ с лимитом расходов
2. **Защитите URL паролем** через Cloudflare Access (бесплатно для команды до 50 человек):
   - Cloudflare Zero Trust → Access → Create Application
   - Authentication: Email + One-time PIN
   - Только сотрудники с email из вашего домена смогут открыть CRM
3. **Не делайте URL индексируемым в Google:** добавьте `<meta name="robots" content="noindex">` в head (уже добавлено в новую версию)

### Максимум (рекомендую для production):

Разверните **прокси-сервер** (Cloudflare Worker или Vercel Function) который:
- Хранит все API-ключи в секретах
- Принимает запросы от вашей CRM (с проверкой авторизации)
- Проксирует запросы к Anthropic/Twilio/Stripe

CRM на фронте при этом никаких ключей не знает. Это занимает 1-2 часа разработки. Скажу как это сделать если попросите.

## Бэкапы

**КРИТИЧНО:** все ваши заказы, клиенты, фото — в localStorage браузера. Если очистить cache браузера или сменить устройство — данные пропадут.

### Регулярно делайте бэкап:

1. **Настройки → Резервная копия → ⬇ Экспорт всех данных (JSON)** — скачивает файл с полной БД
2. Сохраните в облако (Google Drive / Dropbox / iCloud)
3. Делайте раз в неделю минимум, а лучше после каждого важного дня

### Восстановление:

Тот же раздел → **⬆ Импорт данных** → выбрать ранее сохранённый JSON-файл.

# Finance Control PRO для Google Sheets

Готовый Google Apps Script для личного и бизнес-финансового учета:

- счета, наличные, кредитные карты, кредиты и займы;
- доходы, расходы, переводы между счетами;
- семейный и бизнес-контур отдельно;
- подписки, ежемесячные платежи, кредитные платежи;
- платежный календарь и синхронизация с Google Calendar;
- Telegram-уведомления и команды бота;
- заказы/проекты для бизнес-расходов;
- экспорт строк для бухгалтера;
- дашборд, бюджет, аналитика, теги и справочники.

## Standalone HTML-трекер

Файл `StandaloneTracker.html` — отдельная браузерная версия трекера из вставленного кода. Его можно открыть напрямую в браузере; данные хранятся локально в `localStorage`/`IndexedDB`.

Stripe и Telegram ключи больше не хранятся в исходном коде. При первом использовании соответствующей функции трекер попросит restricted Stripe key или Telegram Bot Token/Chat ID и сохранит их только локально в браузере.

## Установка

1. Создайте новую Google Таблицу.
2. Откройте `Расширения -> Apps Script`.
3. Вставьте содержимое `Code.gs` в файл `Code.gs`.
4. Создайте HTML-файл `Sidebar` и вставьте туда `Sidebar.html`.
5. В настройках проекта включите показ файла манифеста и замените `appsscript.json` содержимым из этого пакета.
6. Запустите функцию `setupFinanceSystem`.
7. Выдайте доступы Google.
8. Вернитесь в таблицу и обновите страницу. Появится меню `Finance Control PRO`.

## Telegram

1. Создайте бота через `@BotFather`.
2. В таблице откройте `Finance Control PRO -> Настроить Telegram`.
3. Вставьте `Bot Token` и `Chat ID`.
4. Нажмите `Отправить тест в Telegram`.

Для команд из Telegram:

1. В Apps Script нажмите `Deploy -> New deployment -> Web app`.
2. Execute as: `Me`.
3. Who has access: `Anyone`.
4. Скопируйте Web App URL.
5. В редакторе Apps Script запустите:

```js
setTelegramWebhook('PASTE_WEB_APP_URL_HERE')
```

Команды:

```text
/summary
/payments
/expense 125 scope=business account=BUSINESS_CHECKING cat="Материалы" order=ORDER-001 note="paint"
/income 500 scope=business account=BUSINESS_CHECKING cat="Поступления от клиентов" order=ORDER-001 note="deposit"
```

Для бизнес-расхода скрипт требует `order=...` или `ref=...` / `invoice=...`, чтобы расход не потерялся для учета.

## Ежедневная автоматика

В меню выберите `Finance Control PRO -> Установить ежедневную автоматику`.

Каждый день скрипт:

- обновит платежный календарь;
- создаст операции по подпискам, где включена `Автооперация = Да`;
- синхронизирует ближайшие платежи с Google Calendar;
- отправит Telegram-сводку по просроченным и ближайшим платежам.

## Как вести учет

Основной ввод идет через лист `Операции` или через меню `Быстрый ввод операции`.

Для переводов:

- `Тип = Перевод`;
- `Откуда = счет списания`;
- `Куда = счет поступления`;
- сумма положительная.

Для кредитной карты:

- покупки по карте: `Откуда = ID кредитной карты`;
- погашение карты: `Тип = Погашение карты`, `Откуда = счет оплаты`, `Куда = ID кредитной карты`.

Для бизнеса:

- `Контур = Бизнес`;
- для расходов обязательно указывайте `Заказ` или `Учет`;
- `Бухгалтерия_Экспорт` собирает бизнес-операции, которые еще не синхронизированы.

## Листы

- `Дашборд` - текущий месяц, контроль платежей, бизнес-риски.
- `Операции` - все движения денег.
- `ПлатежныйКалендарь` - ближайшие подписки, карты, кредиты.
- `Подписки` - повторяющиеся оплаты.
- `Счета` - счета, наличные, карты как балансовые сущности.
- `КредитныеКарты` - лимиты, долг, дни платежа.
- `Кредиты` - займы и обязательные платежи.
- `Заказы` - заказы/проекты для бизнес-контроля.
- `Бюджет` - лимиты по категориям.
- `Аналитика` - сводные таблицы.
- `Справочники` - категории, статусы, валюты, методы оплаты.
- `Бухгалтерия_Экспорт` - строки для бухгалтера.
- `Журнал` - технический лог.

# Уведомления на телефон (веб-пуши)

Бесплатно: пуши доставляют службы Apple, Google и Mozilla, CRM подписывает их своим ключом VAPID. Платных сервисов и пакетов нет (`src/features/push/web-push.ts`, RFC 8291 + RFC 8292 на `node:crypto`).

## Что приходит и кому

| Событие | Кому |
| --- | --- |
| Новый лид (таблица `leads`) | владельцы + менеджер лида, а если менеджера нет — все менеджеры |
| Назначен замер (старая CRM: `measurerId`; новая: `consultation.assigned`) | замерщик |
| Назначен монтаж (`installerIds`; `installation.assigned`, `installation.phase_assigned`, `project.manual_assigned`) | монтажник |
| Замер внесён (`status = measurement_done`; `survey.completed`) | менеджер проекта |
| Клиент принял КП (`proposalAcceptedAt` / `proposal_accepted`; `agreement.signed`, `proposal.approved`) | менеджер проекта + владельцы |

- Тому, кто сам сделал действие, пуш не приходит.
- У монтажников и замерщиков в тексте пуша нет сумм (`stripMoney`): экран блокировки видят все.
- Прошедшие визиты (старше суток), закрытые и отменённые проекты не пушатся. Сохранение, которое дало бы больше 20 пушей (импорт, массовая правка), не пушит ничего.
- Одно событие — один пуш человеку (`push_deliveries`, уникальный `event_key` + получатель). Три попытки, не старше 6 часов; записи старше 30 дней удаляются.

## Включить на сервере

1. На сервере: `node scripts/generate-vapid-keys.mjs`.
2. Две строки — в `.env` сервера (не в git). По желанию `VAPID_SUBJECT`.
3. Перезапуск CRM. Без ключей кнопки нет, фоновой работы нет.
4. Выключить, не удаляя ключи: `PUSH_NOTIFICATIONS="off"`.

Новый ключ = все устройства включают уведомления заново.

## Включить на устройстве

- Старая CRM: 🔔 → карточка «Уведомления на телефон» → «Включить уведомления на этом устройстве» → «Проверить».
- Новая CRM: кнопка «Уведомления на телефон» внизу меню.
- iPhone (iOS 16.4+): только из приложения на экране «Домой» (Safari → «Поделиться» → «На экран Домой»), потом включить там.
- Android, компьютер: Chrome, Edge, Firefox — прямо в браузере.

## API

- `GET /api/v1/push` — `{ enabled, public_key, devices }`.
- `POST /api/v1/push/subscriptions` `{ subscription }`, `DELETE` `{ endpoint }` — только свой сеанс, не «просмотр глазами сотрудника» и не API-ключ. Принимаются только адреса служб пушей (FCM, Apple, Mozilla, Windows).
- `POST /api/v1/push/test` — проверочный пуш на свои устройства.
